# Quản lý sinh viên - cách ghép vào project my-app (cấu trúc src/app)

1. Chép vào thư mục gốc my-app (ghi đè khi được hỏi): `src/`, `locales/`, `assets/`, `app.json`.
2. Xóa file mẫu không dùng: `src/app/explore.tsx` (nếu có).
3. `npx expo install @react-native-async-storage/async-storage expo-image-picker expo-localization`
4. `npx expo start -c`
